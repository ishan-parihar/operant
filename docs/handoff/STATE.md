## The claim audit

The sweep's largest class of finding was not a defect in the code but a
**claim in the documentation that the code does not support**. Nine
documentation rows were wrong and are now corrected (BUGS.md RT-45 to
RT-50): the gateway adapter descriptions (the webhook is not a "stub",
WhatsApp/Email/SMS are not "config-only"), the error-class and hook-event
counts, the CLI command count, the overlay count, the crate tree, the
TUI "bridge", and two CLI stubs described with invocations that do not
exist.

One false correction was made and reverted: iter-1000 removed "and server"
from the README's MCP row on a search that covered
`operant-core/src/mcp.rs` only, and missed
`crates/operant-cli/src/mcp_serve.rs` — 955 lines implementing an MCP
SERVER over stdio. The original row was right.

**The rule this suggests:** a claim in a document is worth exactly what the
search behind it covered. A count is not a fact until it has been derived
from the code, and a "this does not exist" finding needs the WHOLE
workspace searched, not one file.
