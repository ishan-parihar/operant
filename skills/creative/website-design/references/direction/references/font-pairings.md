# Font Pairing Reference

Curated display/body/mono pairings. Defaults: Geist + Geist Mono for dev tools, SaaS, B2B.

Rules: pair fonts exactly as listed; serif display requires an editorial/luxury voice AND a neutral sans body; keep emphasis inside one family per headline; no ambient (Fraunces serif lookalikes) outside editorial; mono font must carry numerals and code at small sizes.

Reasoning: each pairing's Category + Best For encodes the reasoning from `ui-ux-pro-max typography.csv`. Classic Elegant = serif contrast for luxury editorial legibility; Minimal Swiss = single-family Inter + tabular mono for enterprise data density; Tech Startup = Space Grotesk/DM Sans dual-sans for geometric display without serif formality. Do not split pairings: display/body were co-selected for x-height, contrast, and voice. Source CSV `Reasoning` field has per-pair prose if needed.
